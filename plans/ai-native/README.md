# AI-Native Product PRDs

These four product bets make DragonFruit the durable home for work across native and external AI interfaces.

## PRDs

1. [031 — Work from Anywhere](031-work-from-anywhere.md)  
   OAuth-authorized MCP, complete safe actions, approval parity, idempotency, auditing, and external-client distribution.

2. [032 — Work That Remembers](032-work-that-remembers.md)  
   Workspace and Project Briefs, visible memory, provenance, context proposals, corrections, and run-level context inspection.

3. [033 — Recurring Operating Loop](033-recurring-operating-loop.md)  
   Weekly planning, review, idempotent execution, blocker follow-up, reporting, scheduling, and recovery.

4. [053 — Project Context Sources](053-project-context-sources.md)  
   A bounded Drive-folder source, portable Claude/Codex handoffs, context packs, provenance, and proposal-only promotion into canonical context.

## Sequence

1. Run the Plan 033 concierge experiment before building orchestration.
2. Run the Plan 031 assisted MCP pilot in parallel.
3. Build Plan 032 as the shared context foundation.
4. Validate Plan 053's compact source-pack workflow, then build the Drive source connection on the Plan 032 safety model.
5. Build Plan 031's production authorization and external tool surface; it may later accept structured client handoffs from Plan 053.
6. Build Plan 033 only after its retention and payment gate passes.
